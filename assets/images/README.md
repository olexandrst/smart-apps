# Інструкція для додавання фото експерта

Щоб додати фото Алекса Стасюка, помістіть файл `alex-stasuk.jpg` в цю папку.

Рекомендовані параметри:
- Формат: JPG або PNG
- Розмір: 400x400px (квадратне)
- Розмір файлу: до 200KB
- Бажано: професійне фото на світлому фоні

Фото буде відображатись круглим з червоним градієнтом навколо.

Якщо фото не буде додане, буде показано емоджі 👨‍🏫.
