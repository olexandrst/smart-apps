# 🚀 AI Launchpad

**Каталог AI-інструментів для курсу "ШІ для бізнесу"**

Веб-застосунок з колекцією найкращих AI-додатків, організованих за категоріями для легкого доступу студентів.

---

## 📋 Опис

AI Launchpad - це інтерактивна стартова сторінка з каталогом AI-інструментів, розроблена спеціально для студентів курсу "ШІ для бізнесу". Застосунок дозволяє швидко знаходити та переходити до потрібних AI-сервісів.

## ✨ Функціональність

- **50+ AI-додатків** організованих за категоріями
- **Розумний пошук** для швидкого знаходження потрібного інструменту
- **Фільтрація за категоріями**: Чат-боти, Автоматизація, Мультимедіа, Бізнес, Інше
- **Адаптивний дизайн** - працює на всіх пристроях
- **Темна тема** для комфортної роботи
- **Прямі посилання** на всі сервіси

## 🚀 Як запустити

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/olexandrst/smart-apps.git
   cd smart-apps
   ```

2. **Відкрийте файл `index.html` у браузері:**
   - Подвійний клік на файлі
   - Або використайте локальний сервер:
     ```bash
     # Python 3
     python -m http.server 8000

     # або Node.js
     npx serve
     ```

3. **Відкрийте у браузері:**
   ```
   http://localhost:8000
   ```

## 🎨 Дизайн

- **Колірна палітра**: Темна тема з градієнтами (фіолетовий/синій)
- **Типографіка**: Системні шрифти для оптимальної продуктивності
- **Адаптивність**: Підтримка екранів від мобільних до desktop
- **Анімації**: Плавні переходи та hover-ефекти

## 🛠️ Технології

- **HTML5** - семантична розмітка
- **CSS3** - сучасні стилі, CSS Grid, Flexbox
- **JavaScript (ES6+)** - динамічний рендеринг та фільтрація
- **Responsive Design** - адаптивна верстка

## 📱 Адаптивність

Застосунок повністю адаптивний та працює на:
- 📱 Мобільних телефонах (320px+)
- 📱 Планшетах (768px+)
- 💻 Ноутбуках (1024px+)
- 🖥️ Великих екранах (1400px+)

## 🔍 Як користуватися

1. **Пошук**: Введіть назву або опис AI-інструменту в пошукове поле
2. **Фільтрація**: Клікніть на категорію для відображення тільки відповідних додатків
3. **Перехід**: Клікніть на картку додатку для відкриття в новій вкладці

## 🤝 Додавання нових AI-додатків

Щоб додати новий AI-інструмент, відредагуйте файл `app.js`:

```javascript
{
    name: 'Назва додатку',
    category: 'chatbots', // або automation, multimedia, business, other
    description: 'Короткий опис',
    url: 'https://example.com',
    icon: '🎨' // Емодзі іконка
}
```
